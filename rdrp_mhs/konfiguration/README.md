# Konfiguration

Die Einstellung des Systems ist in den ersten Augenblicken erschlagend und ganz ehrlich gesagt, ohne Vorerfahrung könnte es hier brenzlig werden, ich habe hier etwas aufgebröselt, damit es für einige von euch vielleicht etwas einfacher wird.&#x20;



Da dieses System auf Realismus baut, sind hier realistische Medizinische Werte hinterlegt, eine Vorkenntnis kann hier Vorteile haben, aber mal ehrlich, wer kennt sich schon mit Blutgaswerten aus?&#x20;



Die Konfigurationsebene für dieses Projekt ist das Ingame Admin Panel, alle anderen Konfigurationen sind auch in einigen Files, diese wären aber viel zu kompliziert für den Start.&#x20;

## <mark style="color:$danger;">**WICHTIG**</mark>

_Das Ingame Admin-Panel speichert eure Veränderungen Ingame bzw. in der Datenbank und ist damit direkt nach der Einstellungen im Spiel übernommen. Veränderungen an der Datei sind nur möglich wenn der Server neugestartet wird._
